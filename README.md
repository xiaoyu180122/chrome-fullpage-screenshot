# 一键长截屏 (Chrome Full Page Screenshot) - DevTools 原生双引擎驱动

> **彻底告别繁琐与长度限制**：无需在网页右键点击检查、打开控制台三点菜单、Run Command 输入 `full` 再回车！  
> 现在只需**在工具栏点一下图标**（或按下快捷键 `Alt+Shift+S`），无论是一般网页、GitHub 深度文档，还是**超长条漫/长篇漫画/无限滚动长文**，都能**一路截到底，彻底解除长度限制**！

## 📝 最近更新日志 (Changelog)

### v1.3.0 (最新修复)
1. **彻底解决未截到底、底部提前被截断问题（完美支持 GitHub 等复杂页面）**：
   - **破解 `content-visibility: auto` 虚拟渲染**：GitHub README、各大技术博客及现代论坛采用 `content-visibility: auto` 跳过未进入视口元素的排版，导致初始测算的高度远小于实际高度。新版本通过 CSS 强制展开全部 DOM 树排版；
   - **智能预热与底部探测**：截屏前执行毫秒级极速扫描，激活所有 `loading="lazy"` 图片（如 GitHub 截图、头像）的真实高度计算；
   - **绝对物理边界探测**：自动扫描网页最底部的 `footer`、版权栏、免责声明等元素的绝对物理底边（`BoundingClientRect.bottom`），确保**从网页第一行一直完整截取到最底部的页脚版权栏，绝不提前截断**；
   - **视口覆写后二次动态修正**：捕捉在扩展视口后因响应式布局重排而产生的额外高度，实现双保险。

### v1.2.0
1. **彻底修复超长漫画 `OffscreenCanvas zero size` 报错**：

2. **彻底打破 16,384px 显卡纹理硬限制（无长度限制截到底）**：
   - 引入超长多段无缝切片拼接引擎，自动将长篇漫画按安全高吞吐块抓取，支持 30,000px ~ 150,000px+ 完整长图全自动截取。
3. **吸顶导航栏（Fixed/Sticky Header）智能去重**：
   - 多段切片捕获时自动隐匿网页中的悬浮吸顶栏，确保顶部导航栏只在最顶端出现一次，漫画画面之间完美无缝拼接。
4. **实时进度反馈与 0% DOM 污染**：
   - 截屏过程中不向宿主网页插入任何遮挡元素（彻底根除右上角提示浮窗被截进画面的问题）；
   - 浏览器工具栏图标角标实时呈现切片进度（`1/5`、`2/5`、`拼装`、`✓`）。

## ✨ 核心优势与特色

1. **全新自适应双引擎架构**
   - **常规页面 (≤ 16,000px)**：采用原生 `Emulation.setDeviceMetricsOverride` 极速单帧渲染，300ms 秒级下载；
   - **超长长图 (> 16,000px)**：针对**长篇条漫、网漫 (Webtoon)、超长数据报表**，自动无缝切换至**多段切片拼接引擎**，真正做到“一路截到底”。
2. **零遮挡（0% 网页污染）**
   - 截屏过程中不向宿主网页插入任何遮挡元素，仅在扩展图标角标显示状态，截图 100% 干净纯粹。
3. **三端多重触发方式**
   - **工具栏图标**：单击一次直接截取；
   - **全局快捷键**：`Alt + Shift + S`（Windows）/ `Command + Shift + S`（Mac）；
   - **右键上下文菜单**：右键网页任意处 -> 选择「📸 一键全页长截屏 (无长度限制)」。
4. **高度可自定设置 (Options)**
   - 导出格式：PNG（无损推荐）/ JPEG / WebP；
   - 图像质量：50% ~ 100% 动态调节；
   - 智能防空白预滚：可选针对小红书/知乎等强懒加载（Lazy-load）站点进行极速预滚以唤醒图片；
   - 自定义文件名模板：支持 `{title}`, `{domain}`, `{date}`, `{time}` 占位符。

## 🚀 30秒安装与更新使用教程

### 如果你是首次安装：
1. **方式 A（一键快捷）**：双击运行本目录下的 `一键打开扩展安装页面.bat`；
2. **方式 B（手动输入）**：在 Chrome 地址栏访问 `chrome://extensions/`；
3. 打开右上角的 **「开发者模式」** 开关；
4. 点击左上角的 **「加载已解压的扩展程序」**，选中本插件目录 `D:\antigravity\sittch\chrome-fullpage-screenshot` 即可。

### 如果你已安装过（更新生效）：
1. 在 Chrome 中打开 `chrome://extensions/`；
2. 找到 **「一键长截屏」** 插件卡片；
3. 点击卡片右下角的 **「重新加载」 (圆圈刷新图标 🔄)**；
4. 回到刚才的网页，**按 F5 刷新一下该网页**，再次点击图标（或按 `Alt+Shift+S`）即可！
