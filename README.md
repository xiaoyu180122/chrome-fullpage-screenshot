# 一键长截屏 (Chrome Full Page Screenshot) - DevTools 原生双引擎驱动

> **彻底告别繁琐与长度限制**：无需在网页右键点击检查、打开控制台三点菜单、Run Command 输入 `full` 再回车！  
> 现在只需**在工具栏点一下图标**（或按下快捷键 `Alt+Shift+S`），无论是一般网页还是**超长条漫/长篇漫画/无限滚动长文**，都能**一路截到底，彻底解除长度限制**！

---

## ✨ 核心优势与特色

1. **全新双引擎架构：无长度限制截到底**
   - **普通页面 (≤ 16,000px)**：采用原生 `Emulation.setDeviceMetricsOverride` 极速单帧渲染，300ms 秒级下载；
   - **超长长图 (> 16,000px)**：针对**长篇条漫、网漫 (Webtoon)、超长数据报表**，自动无缝切换至**多段切片拼接引擎**，突破浏览器 GPU 16,384px 的硬限制，支持 30,000px ~ 150,000px+ 完整截取，真正做到“截到底”。
2. **吸顶导航栏（Fixed/Sticky Header）智能去重**
   - 在多切片滚动截取过程中，自动隐藏固定悬浮栏，确保**顶部导航条只在长图最顶端呈现一次**，彻底消除“千层饼”重复叠层与遮挡问题。
3. **点一下直接保存（零冗余弹窗、0% 网页污染）**
   - 截屏过程中不向宿主网页插入任何遮挡元素，仅在浏览器图标角标显示实时截取进度（如 `1/4`、`2/4`、`✓`）；
   - 调试连接在截屏完成后毫秒级自动断开，绝不残留顶部黄色调试栏。
4. **三端多重触发方式**
   - **工具栏图标**：单击一次直接截取；
   - **全局快捷键**：`Alt + Shift + S`（Windows）/ `Command + Shift + S`（Mac）；
   - **右键上下文菜单**：右键网页任意处 -> 选择「📸 一键全页长截屏 (无长度限制)」。
5. **高度可自定设置 (Options)**
   - 导出格式：PNG（无损推荐）/ JPEG / WebP；
   - 图像质量：50% ~ 100% 动态调节；
   - 智能防空白预滚：可选针对小红书/知乎等强懒加载（Lazy-load）站点进行极速预滚以唤醒图片；
   - 自定义文件名模板：支持 `{title}`, `{domain}`, `{date}`, `{time}` 占位符。

## 🚀 30秒安装与更新使用教程

### 如果你是首次安装：
1. **方式 A（一键快捷）**：双击运行本目录下的 `一键打开扩展安装页面.bat`；
2. **方式 B（手动输入）**：在 Chrome 地址栏访问 `chrome://extensions/`；
3. 打开右上角的 **「开发者模式」** 开关；
4. 点击左上角的 **「加载已解压的扩展程序」**，选中本插件目录 `D:\antigravity\sittch\chrome-fullpage-screenshot` 即可。

### 如果你已安装过（更新生效）：
1. 在 Chrome 中打开 `chrome://extensions/`；
2. 找到 **「一键长截屏」** 插件卡片；
3. 点击卡片右下角的 **「重新加载」 (圆圈刷新图标 🔄)**；
4. 回到刚才要截屏的超长漫画或长网页，**按 F5 刷新一下该网页**，再次点击图标或按 `Alt+Shift+S` 即可体验一路截到底！

## ⚙️ 选项设置

- 右键点击工具栏上的插件图标，选择 **「选项」**，即可进入高级设置面板；
- 也可在任意网页右键选择 **「长截屏设置选项...」**。
