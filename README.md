# 一键长截屏 (Chrome Full Page Screenshot) - DevTools 原生引擎驱动

> **彻底告别繁琐**：无需在网页右键点击检查、打开控制台三点菜单、Run Command 输入 `full` 再回车！  
> 现在只需**在工具栏点一下图标**（或按下快捷键 `Alt+Shift+S`），300ms 内直接保存整页高清长截图并自动下载。

---

## ✨ 核心优势与特色

1. **Chrome DevTools 底层原生渲染（CDP `Page.captureScreenshot`）**
   - 与控制台 `Run > Capture full size screenshot` 共享完全一致的浏览器内部底层引擎；
   - **吸顶导航栏（Fixed/Sticky Header）不重复**：不同于传统的“不断向下滚动页面+Canvas拼接”插件，原生渲染机制会在全局页面布局中仅渲染一次顶部栏，彻底消除多层重叠切片、画面撕裂或接缝错位问题。
2. **点一下直接保存（零冗余弹窗）**
   - 点击插件图标后直接启动后台截屏并自动触发下载，耗时通常只需 300~600ms；
   - 调试连接使用 `try...finally` 在截屏完成毫秒级自动断开，绝不残留顶部调试信息提示条。
3. **三端多重触发方式**
   - **工具栏图标**：单击一次立即截屏；
   - **全局快捷键**：`Alt + Shift + S`（Windows）/ `Command + Shift + S`（Mac）；
   - **右键上下文菜单**：右键网页任意处 -> 选择「📸 一键全页长截屏」。
4. **精致微动效交互反馈 (Emil Kowalski 规范)**
   - 网页右上角注入高品质毛玻璃动态提示胶囊（Shadow DOM 独立隔离，不破坏网页原有样式）；
   - 工具栏角标状态同步（`⏳` 截取中，`✓` 成功，`ERR` 异常）。
5. **高度可自定设置 (Options)**
   - 导出格式：PNG（无损推荐）/ JPEG / WebP；
   - 图像质量：50% ~ 100% 动态调节；
   - 分辨率缩放：1x 标准 / 2x Retina 超高清；
   - 智能防空白预滚：可选针对小红书/知乎等强懒加载（Lazy-load）站点进行 150ms 闪电预滚以唤醒图片；
   - 自定义文件名模板：支持 `{title}`, `{domain}`, `{date}`, `{time}` 占位符。

## 🚀 30秒安装使用教程

### 第一步：打开 Chrome 扩展管理
你有两种最简单的方式：
1. **方式 A（一键快捷）**：双击运行本目录下的 `一键打开扩展安装页面.bat`；
2. **方式 B（手动输入）**：在 Chrome 地址栏输入并访问 `chrome://extensions/`。

### 第二步：开启开发者模式并加载
1. 在扩展页面右上角，打开 **「开发者模式」 (Developer mode)** 开关；
2. 点击左上角出现的 **「加载已解压的扩展程序」 (Load unpacked)** 按钮；
3. 在弹出的文件夹选择框中，选中当前插件目录：  
   `D:\antigravity\sittch\chrome-fullpage-screenshot`  
4. 点击「选择文件夹」。

### 第三步：固定图标并体验一键长截屏
1. 点击 Chrome 右上角的拼图图标（扩展程序菜单），找到 **「一键长截屏」**，点击旁边的**图钉📌图标**将其固定到工具栏；
2. 打开任意你想要截屏的网页（例如知乎、Github、文章博客等）；
3. **直接点击一下右上角的相机插件图标**（或按下 `Alt+Shift+S`）；
4. 页面右上角将浮现动态胶囊提示，长截图将在 1 秒内自动下载到你的浏览默认「下载」文件夹！

## ⚙️ 选项设置

- 右键点击工具栏上的插件图标，选择 **「选项」**，即可进入高级设置面板；
- 也可在任意网页右键选择 **「长截屏设置选项...」**。

## ⚠️ 注意事项与常见问题

1. **为什么在某些页面点击显示 ERR 或不截图？**
   - 谷歌 Chrome 出于安全机制，**严格禁止任何扩展程序在 Chrome 内部系统页（如 `chrome://extensions`、设置页）以及 Chrome Web Store 应用商店内注入脚本或连接调试**。请在外部普通网页（如新闻、博客、电商、社交网站等）上使用。
2. **提示“当前页面已打开 F12 控制台”？**
   - Chrome 只允许同时存在一个调试器连接。如果你当前页面已经打开了 F12 开发者工具，请先按 F12 或关闭开发者面板，再点击插件截屏即可。
