# 一键长截屏 (Chrome & Edge Full Page Screenshot) - 原生双引擎驱动

> **彻底告别繁琐与长度限制**：无需在网页右键点击检查、打开控制台三点菜单、Run Command 输入 `full` 再回车！  
> 现在只需**在 Chrome / Edge 工具栏点一下图标**（或按下快捷键 `Alt+Shift+S`），无论是一般网页、GitHub 深度文档，还是**超长条漫/长篇漫画/无限滚动长文**，都能**一路截到底，彻底解除长度限制**！

### v1.4.0 (画质与清晰度重磅升级)
1. **彻底保障 100% 原始画质直出（绝无任何画质压缩）**：
   - **天然无损 PNG 输出**：默认格式为标准 **PNG（无损 Lossless）**，基于 Deflate 纯无损编码算法，每个像素的 RGB 色值与显卡实际渲染 100% 比对一致，绝不引入任何 JPEG 压缩色块、边缘杂色或降噪模糊；
   - **质量参数拉满至 100%**：底层质量参数调满至 `100`，彻底杜绝任何算法级潜在降质。
2. **新增「💻 原屏物理 DPI 点对点」高清直出支持**：
   - **痛点根治**：以往采用标准 1x 逻辑像素导出，在 Windows 开启 125%/150% 缩放的屏幕上查看时会被系统相册二次拉伸变虚。
   - **原屏渲染直出**：自动探测并适配当前显示器的真实物理缩放比（`window.devicePixelRatio`），按 1:1 物理像素进行原画渲染，截出的文字、代码及图标与肉眼在屏幕上所见完全一致，极致锐利；
   - **多档分辨率随心切换**：设置页支持切换 `1x 标准点对点` / `💻 原屏物理DPI (默认推荐)` / `2x Retina 超清`。
3. **Canvas 拼装管道零插值保护**：
   - 禁用双线性模糊平滑插值（`imageSmoothingEnabled = false`），切片拼装采用物理像素级精确定位，保证超长长图画质分毫未损。

### v1.3.1
1. **彻底修复超长切片拼接错位与底部内容重复问题 (Scroll Clamping Overlap Resolution)**：
   - **深入根因**：超长页面在滚动切片到达页面最底部时，受浏览器原生 DOM 滚动机制限制，`window.scrollY` 会被强制钳位在最大可滚动距离（`scrollHeight - viewportHeight`），导致最后一段切片若盲目绘制，会把中段已截取的内容（如卡片/截图）重复粘贴至末尾；
   - **高精度数学去重裁剪算法**：实时获取浏览器物理视口渲染真实坐标（`actualY`），自动计算切片之间的重叠高度（`overlap`），利用 Canvas 精确提取无重叠子区域进行拼接。保证从顶部一直顺延到最末尾的页脚（Footer），**0 重复、0 断层、0 错位**；
   - **切片颗粒度与性能优化**：切片调整为 5,000px 安全高吞吐视口，配合轻量级吸顶元素选择器，消除全量 DOM 遍历开销，截屏与拼接过程更加流畅稳定。

### v1.3.0
1. **彻底解决未截到底、底部提前被截断问题（完美支持 GitHub 等复杂页面）**：
   - **破解 `content-visibility: auto` 虚拟渲染**：GitHub README、各大技术博客及现代论坛采用 `content-visibility: auto` 跳过未进入视口元素的排版，导致初始测算的高度远小于实际高度。新版本通过 CSS 强制展开全部 DOM 树排版；
   - **智能预热与底部探测**：截屏前执行毫秒级极速扫描，激活所有 `loading="lazy"` 图片（如 GitHub 截图、头像）的真实高度计算；
   - **绝对物理边界探测**：自动扫描网页最底部的 `footer`、版权栏、免责声明等元素的绝对物理底边（`BoundingClientRect.bottom`），确保**从网页第一行一直完整截取到最底部的页脚版权栏，绝不提前截断**；
   - **视口覆写后二次动态修正**：捕捉在扩展视口后因响应式布局重排而产生的额外高度，实现双保险。

## ✨ 核心优势与特色

1. **全新自适应双引擎架构**
   - **常规页面 (≤ 16,000px)**：采用原生 `Emulation.setDeviceMetricsOverride` 极速单帧渲染，300ms 秒级下载；
   - **超长长图 (> 16,000px)**：针对**长篇条漫、网漫 (Webtoon)、超长数据报表**，自动无缝切换至**多段切片拼接引擎**，真正做到“一路截到底”。
2. **零遮挡（0% 网页污染）**
   - 截屏过程中不向宿主网页插入任何遮挡元素，仅在扩展图标角标显示状态，截图 100% 干净纯粹。
3. **三端多重触发方式**
   - **工具栏图标**：单击一次直接截取；
   - **全局快捷键**：`Alt + Shift + S`（Windows）/ `Command + Shift + S`（Mac）；
   - **右键上下文菜单**：右键网页任意处 -> 选择「📸 一键全页长截屏 (无长度限制)」。
4. **高度可自定设置 (Options)**
   - 导出格式：PNG（无损推荐）/ JPEG / WebP；
   - 图像质量：50% ~ 100% 动态调节；
   - 智能防空白预滚：可选针对小红书/知乎等强懒加载（Lazy-load）站点进行极速预滚以唤醒图片；
   - 自定义文件名模板：支持 `{title}`, `{domain}`, `{date}`, `{time}` 占位符。

## 🚀 30秒极速安装与更新教程

### A. 安装至 Microsoft Edge 浏览器：
1. **一键直达**：双击运行本目录下的 `一键安装至Edge浏览器.bat`（或在 Edge 地址栏输入 `edge://extensions/` 回车）；
2. **开启开发模式**：在 Edge 页面**左侧边栏**最下方，打开 **「开发人员模式」** 开关；
3. **加载插件**：点击顶部出现的 **「加载解压缩的扩展」** 按钮；
4. **选择目录**：在弹出的文件夹选择框中，选中当前插件文件夹：
   ```text
   D:\antigravity\sittch\chrome-fullpage-screenshot
   ```
5. **固定图标**：点击 Edge 地址栏右侧的拼图图标 🧩，将 **「一键长截屏」** 固定到工具栏即可！

### B. 安装至 Google Chrome 浏览器：
1. **一键直达**：双击运行本目录下的 `一键安装至Chrome浏览器.bat`（或在 Chrome 地址栏输入 `chrome://extensions/` 回车）；
2. **开启开发模式**：在 Chrome 页面**右上角**，打开 **「开发者模式」** 开关；
3. **加载插件**：点击左上角的 **「加载已解压的扩展程序」** 按钮；
4. **选择目录**：选中当前插件文件夹 `D:\antigravity\sittch\chrome-fullpage-screenshot` 即可。

### 如果你已安装过（更新代码生效）：
1. 在浏览器扩展管理页面找到 **「一键长截屏」** 卡片；
2. 点击卡片上的 **「重新加载」 (圆圈刷新图标 🔄)**；
3. 回到刚才的网页，**按 F5 刷新一下该网页**，再次点击图标（或按 `Alt+Shift+S`）即可生效最新功能！
